Stickly 📝

A simple, lightweight sticky-note application for Windows.

Stickly is a Windows-based desktop application designed to provide a quick and convenient way to create and manage notes directly on your desktop.

Whether you need to jot down a reminder, save a piece of information temporarily, or keep an important task visible while working, Stickly aims to keep note-taking simple and accessible.

✨ Features
📝 Create and manage sticky notes
🖥️ Designed specifically for Windows
⚡ Lightweight desktop application
🎯 Simple and distraction-free interface
📌 Keep important information easily accessible
💻 Runs locally on your computer
🛠️ Tech Stack
Language: C#

🚀 Getting Started

Before building Stickly, make sure you have:

Visual Studio

Navigate into the project:

cd Stickly
Build and Run
Open the project in Visual Studio.
Restore the required dependencies.
Build the solution.
Run the application.
💡 Why Stickly?

Traditional note-taking applications can sometimes require unnecessary navigation just to write down a quick thought.

Stickly is intended to make that process faster by providing a lightweight desktop environment for keeping short notes close at hand.
